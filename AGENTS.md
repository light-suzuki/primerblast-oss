# Public repository data boundary

- This repository is public. Commit only synthetic fixtures or data with a documented public source.
- Keep private genomes, annotations, variants, reference catalogs, project exports and raw local reports outside the repository or in ignored local directories. Do not force-add them.
- Do not put personal absolute paths, machine names, credentials, private cultivar identifiers, sequences or coordinates in commits, issues, PR descriptions or screenshots shared on GitHub.
- Before publishing, review the staged diff and generated reports for these fields. Preserve a local original when redacting a published report, and preserve scientific measurements and public provenance.
- The browser and future agent layer must use the same local reference catalog. A local path or reference identifier is not permission to send its contents to an external service.
